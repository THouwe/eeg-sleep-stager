# Serve-time dependencies for the Gradio web demo (Docker / Koyeb install list).
#
# This is the model-SERVING environment. Three deliberate choices:
#   * NO tensorflow -- the CNN is served from models/cnn.onnx via onnxruntime
#     (a fraction of TF's size/RAM), so the demo fits a free 512 MB host. The
#     TF/Keras path stays in the code (commented / retained) but is never
#     imported on the serve path. See cnn-to-onnx.md.
#   * NO pyspark -- Spark only builds the epoch store offline; inference
#     (app.py / inference.py) is plain MNE/NumPy/onnxruntime and never touches a
#     cluster. Importing eeg_sleep_stager.inference pulls no Spark.
#   * NO "." (the local package) -- app.py puts ./src on sys.path itself, so the
#     package imports from a bare checkout without a pip install that would drag
#     the pipeline's pyspark/typer pins back in.
#
# The gradio stack is pinned to a mutually compatible set: gradio 4.44.1 breaks
# against the newest fastapi/starlette/huggingface_hub/pydantic (ASGI + schema
# errors), so those are held at the tested versions. pydantic stays at the
# pipeline's 2.6.4.
